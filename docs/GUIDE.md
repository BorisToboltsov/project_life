# Руководство

Приложение не является медицинским изделием и не заменяет консультацию врача.

## Установка на телефон

Приложение открывается в браузере и ставится на домашний экран — после этого оно
запускается как обычное, без адресной строки.

- **Android, Chrome:** меню браузера → «Установить приложение».
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».

## Регистрация

Зарегистрироваться можно только по ссылке-приглашению от администратора. Откройте её,
укажите имя, адрес почты и пароль не короче 10 символов. Ссылка работает один раз и
действует 7 дней.

Адрес почты служит только именем для входа: писем приложение не отправляет.

## Вход и выход

Входите по адресу почты и паролю. На своём устройстве повторно входить не придётся:
сессия продлевается сама, пока вы пользуетесь приложением хотя бы раз в 30 дней.

В разделе «Профиль»:

- **«Выйти»** — завершает сеанс на этом устройстве.
- **«Выйти на всех устройствах»** — завершает все сеансы, например после потери телефона.

После нескольких неверных паролей подряд вход временно закрывается — подождите
15 минут.

## Профиль

В разделе «Профиль» задаются имя, пол, дата рождения и рост, а также настройки:

- **Язык** — русский или английский.
- **Часовой пояс** — по нему считаются дни и показывается время.
- **Единицы** — метрические или имперские. После смены рост вводится в футах и дюймах.

Пол, дата рождения и рост понадобятся для расчёта целей по питанию; заполнять их не
обязательно.

## Пароль

- **Сменить:** «Профиль» → «Смена пароля». На остальных устройствах сеансы завершатся.
- **Забыли:** попросите администратора прислать ссылку для сброса. Она работает один раз
  и действует сутки.

## Администратору

### Первый администратор

Первую ссылку-приглашение выпускают командой на сервере:

```bash
docker compose exec backend python -m app.cli invite --admin
```

Команда печатает ссылку; откройте её и зарегистрируйтесь.

### Приглашения

«Управление» → «Приглашения» → «Создать приглашение». Пометка «для кого» видна только
вам. Ссылка показывается один раз — скопируйте и отправьте её сразу. Неиспользованное
приглашение можно отозвать.

Приглашение с ролью «Администратор» даёт те же права, что у вас.

### Сброс пароля

«Управление» → «Пользователи» → «Ссылка для сброса пароля» напротив нужного человека.
Ссылка показывается один раз.
