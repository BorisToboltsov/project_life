# ADR 0017 — группы тренировок с расписанием

## Контекст

Повтор прошлой тренировки требует уже записанного занятия. Нужны несколько заранее
подготовленных наборов упражнений и календарь, подсказывающий набор на сегодня.

## Решение

Группа хранит название и упорядоченный набор ссылок на упражнения. У неё есть дни недели
(понедельник — 0), дата начала, необязательная дата окончания и дополнительные даты.
Группа попадает в план дня, если день подходит недельному правилу внутри периода **или**
явно указан среди дополнительных дат. Совпадение обоих условий даёт одну карточку.
Пустое расписание допускает ручной запуск; в один день может быть несколько групп.

Сервер вычисляет сегодняшний день в часовом поясе профиля. На экране сначала показан план
на сегодня, затем все группы. Альтернатива — недельный календарь как основной экран —
отложена: для ежедневного запуска выбран короткий список групп.

При запуске клиент задаёт UUIDv7 тренировки и её упражнений; сервер копирует состав одной
транзакцией. Отдельные назначения на каждую дату заранее не создаются. Правки недельного
правила поэтому сразу меняют вычисляемый план. Записанная история отделена от плана (I17).

Группы удаляются в архив, чтобы сохранялась связь источника при повторе запроса запуска.
Убранные из личного списка упражнения не исключаются молча: перед запуском состав группы
нужно исправить или вернуть упражнение. Заданные веса, повторы и количество подходов в
группе не хранятся: при записи по-прежнему подставляется предыдущий результат.

## Последствия

Нет фоновых задач генерации календаря. Дополнительные даты действуют вне недельного периода.
Перенос одного регулярного занятия и исключения дат потребуют отдельного расширения модели.
Группа доступна для запуска вне расписания; действует прежнее ограничение одной активной
тренировки на пользователя.
