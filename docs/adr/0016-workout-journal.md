# ADR 0016 — журнал тренировок

## Контекст

Выбранное упражнение должно быть видно на экране тренировки ещё до первого подхода.
История остаётся после удаления упражнения из личного списка. Повторение тренировки
переносит состав, а график строится по фактически записанным подходам.

## Решение

- Тренировка, упражнение внутри тренировки и подход — отдельные записи с UUIDv7 от клиента.
  Упражнение внутри тренировки хранит порядок; подход ссылается на него.
- Одна незавершённая тренировка на пользователя закреплена частичным уникальным индексом.
  Завершённая тренировка закрыта для записи новых подходов.
- Вес хранится в килограммах, дистанция — в километрах; исходные значение и единица тоже
  сохраняются. Вид подхода берётся из упражнения, сервер отклоняет поля другого вида.
- Отдых задан у упражнения в секундах. Обратный отсчёт живёт в сеансе вкладки и подаёт
  только вибрацию; это состояние не влияет на журнал.
- Прогресс вычисляется из завершённых тренировок. Повтор создаёт новую тренировку с
  прежним порядком доступных упражнений и пустыми подходами одной транзакцией.

## Последствия

Упражнение может оставаться в истории после удаления из личного списка. График меняется,
после завершения новой тренировки, изменения её времени или удаления тренировки. Незавершённый отсчёт отдыха после
закрытия вкладки исчезает.
