# CHANGELOG

## 0.2.3 — 2026-10-05

- Обновление сервера — вручную: таймер автообновления убран, новую версию ставит команда
  `life-update`. Повторная установка снимает таймер, оставшийся от прежних версий.
- `life-update` сообщает, когда обновлять нечего.

## 0.2.2 — 2026-10-05

- `life-update` не запускается дважды одновременно: таймер и ручной запуск ждут друг друга.
- Установщик включает таймеры после первого запуска приложения, а не до него.
- Инструкция ставит Docker из репозитория Ubuntu; гейт выкладки проверяет скрипты с теми
  же пакетами.

## 0.2.1 — 2026-10-05

- Выкладка: CI публикует образы в GitHub Container Registry, сервер забирает их сам по
  таймеру и перед обновлением делает бэкап.
- Установщик `deploy/install.sh`, скрипты `life-update` и `life-backup`, таймеры systemd.
- Бэкапы базы шифруются открытым ключом age; закрытый ключ на сервере не хранится.
- HTTP/3 выключен: приложение занимает только TCP-порты 80 и 443.
- Инструкция по установке и разбор ошибок; гейт `make check-deploy`.

## 0.2.0 — 2026-10-05

- Замеры тела: вес, шея, талия и бёдра — ввод с главной, правка, удаление, история.
- График показателя за период с линией тренда за 7 дней.
- Анимированные подсказки у каждого показателя: куда встать и где держать ленту.
- Значения в килограммах и сантиметрах либо в фунтах и дюймах — по настройке профиля.
- Раздел «Замеры» в меню; на главной — последние значения и изменение к предыдущему.

## 0.1.0 — 2026-10-05

- Вход и регистрация по приглашению администратора; JWT с ротацией refresh-токена, выход на
  одном и на всех устройствах, ограничение частоты попыток входа.
- Смена пароля и сброс по одноразовой ссылке от администратора.
- Профиль: имя, пол, дата рождения, рост, язык, часовой пояс, единицы измерения. Даты
  вводятся и показываются в порядке «день, месяц, год».
- Каркас интерфейса: разделы внизу экрана на телефоне и в колонке слева на компьютере;
  раздел «Управление» для администратора — приглашения и пользователи.
- Команда `python -m app.cli invite --admin` для первого администратора.
- Гейт изоляции: эндпоинт закрыт, пока явно не объявлен открытым.

## 0.0.1 — 2026-10-05

- Каркас бэкенда: FastAPI, SQLAlchemy, Alembic, эндпоинт `/api/health`.
- Каркас фронтенда: устанавливаемая PWA-заглушка на русском и английском, типы API
  генерируются из OpenAPI.
- Стенд в контейнерах: PostgreSQL, миграции, бэкенд, Caddy со статикой фронтенда.
- Гейты и CI: линтеры, типы, тесты с порогами покрытия, миграции, типы API, версия,
  сквозной смоук.
- Документы: инварианты, архитектура, тесты, ADR 0001–0004.
