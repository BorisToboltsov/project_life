# project_life

Веб-приложение для учёта питания, тренировок и показателей здоровья. Работает в браузере
на компьютере и ставится на телефон как PWA. Рассчитано на семью и друзей: вход по
приглашениям, данные каждого пользователя закрыты от остальных.

**Состояние:** готовы вход по приглашениям, профиль, замеры тела — вес, обхваты, процент
жира и свои показатели, — дневник питания с каталогом продуктов, порциями и упаковками,
целью на день, сканером штрихкодов и поиском продуктов в Open Food Facts, учёт воды и
список упражнений с рисунками техники и картой мышц, журнал тренировок, подходы, таймер
отдыха, прогресс, повтор тренировки и группы с расписанием, блюда из своих продуктов
и статистика питания за неделю и месяц (версии 0.1–0.9), запись тренировок, дневника питания и воды без сети
(0.10.0–0.10.1);
выкладка на свой сервер описана в [docs/INSTALL.md](docs/INSTALL.md). Что
будет дальше — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Что запланировано

- **Без сети:** незнакомый штрихкод, распознанный, когда вернётся связь, и замеры.
- **Тренировки:** физические тесты и подводящие упражнения.
- **Здоровье:** вес, анализы, назначения врачей, календарь приёма лекарств.

## Быстрый старт

Нужны Python 3.14 с [uv](https://docs.astral.sh/uv/), Node 24 с pnpm, Docker и make.

```bash
make install
make dev-backend     # в одном терминале
make dev-frontend    # в другом; приложение — на http://localhost:5173
make admin-invite    # ссылка, по которой регистрируется первый администратор
```

Полный прогон всех проверок — `make check`.
