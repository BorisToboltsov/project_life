# project_life

Веб-приложение для учёта питания, тренировок и показателей здоровья. Работает в браузере
на компьютере и ставится на телефон как PWA. Рассчитано на семью и друзей: вход по
приглашениям, данные каждого пользователя закрыты от остальных.

**Состояние:** идёт фаза 0 — каркас разработки. Что будет дальше — в
[docs/ROADMAP.md](docs/ROADMAP.md).

## Что запланировано

- **Питание:** дневник по приёмам пищи, сканер штрихкодов, итог дня против целей.
- **Тренировки:** журнал подходов, прогресс, подводящие упражнения.
- **Здоровье:** вес, анализы, назначения врачей, календарь приёма лекарств.

## Быстрый старт

Нужны Python 3.14 с [uv](https://docs.astral.sh/uv/), Node 24 с pnpm, Docker и make.

```bash
make install
make dev-backend     # в одном терминале
make dev-frontend    # в другом; приложение — на http://localhost:5173
```

Полный прогон всех проверок — `make check`.
